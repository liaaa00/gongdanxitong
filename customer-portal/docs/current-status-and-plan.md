## 2. 已纠正的角色边界

### 客户门户只提供

- 入职办理、离职办理、薪资确认；
- 附件上传和 Excel 批量导入；
- 客户自己的办理进度和结果查询。

### 内部工单系统提供

- 客户规则配置，由业务员或具备权限的内部人员维护；
- 电子签渠道、合同主体、缴纳地、缴费比例、材料收集方式等默认规则；
- 客户结果邮件收件人/抄送人配置；
- 工单审核、补全、处理和办结；
- 邮件发送记录、失败重试和异常处理。

客户门户中的“内部客户配置”入口及配置表单已经移除。客户只能看到规则自动带入后的结果，不能查看或修改内部配置。

## 3. 办结结果确认邮件的正确范围

该功能属于一期需求，不等同于薪资催办邮件，也不等同于公共邮箱分流。

```text
工单状态首次进入 completed（已完成）
  → 读取客户指定联系人
  → 生成该业务类型的关键办理结果 Excel
  → 通过公共邮箱发送确认邮件
  → 保存发送时间、收件人、附件版本和发送结果
  → 发送失败进入重试/人工处理队列
```

详细边界见 `docs/completion-result-email.md`。

## 5. 当前需要业务确认的阻断项

1. 办结结果邮件业务范围已确认：入职、离职、薪资全部包含；剩余是各类型结果模板字段。
2. 各业务类型结果 Excel 的最终字段和模板仍需后台/业务侧提供。
3. 收件人、抄送人由哪个内部页面维护；是否必须抄送对应业务员。
4. 客户异议期限以及“逾期默认确认”的邮件表述。
5. 工单重新打开后再次办结，是否需要再次发送及如何标识版本。
6. 正式公共邮箱的 SMTP/API 接入方式、发件人名称和失败告警接收人。
7. 历史开户地、是否需要工资单等字段已从客户门户移除；如后台仍需维护，必须作为内部配置处理。
8. 服务器环境的数据库凭据、服务身份和接口地址仍待确认；本地 PostgreSQL 迁移已执行，未连接服务器数据库。
9. 正式短信/邮件验证码服务和服务身份认证方式。
