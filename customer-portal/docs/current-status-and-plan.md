## 3. 已确认的角色边界

### 客户门户只提供

- 入职办理、离职办理、薪资确认；
- 附件上传和 Excel 批量导入；
- 客户自己的办理进度和结果查询。

### 内部工单系统提供

- 客户规则配置，由业务员或具备权限的内部人员维护；
- 电子签渠道、合同主体、缴纳地、缴费比例、材料收集方式等默认规则；
- 客户结果邮件收件人/抄送人配置；
- 工单审核、补全、处理和办结；
- 邮件发送记录、失败重试和异常处理。

客户门户不提供内部配置入口。客户填写业务资料，并按允许的选项选择缴纳地、公积金比例等本次办理信息；通用默认值和历史值不能覆盖客户本次合法选择。账号始终归属客户 UUID，客户不需要选择或理解内部商社编码。

## 4. 邮件和提醒的当前口径

该功能属于一期需求，不等同于薪资催办邮件，也不等同于公共邮箱分流。

```text
工单办结（按办结版本防止重复入队）
  → 读取客户指定联系人
  → 生成该业务类型的关键办理结果 Excel
  → 保存待发送任务，由已启用且配置完成的邮件服务投递
  → 保存发送时间、收件人、附件版本和发送结果
  → 发送失败进入重试/人工处理队列
```

入职、离职、薪资均支持办结结果邮件；发送关闭或失败不应显示为已送达。正式 SMTP 按用户要求后配，默认 `MAIL_ENABLED=false`。本轮入离职全流程验收仅确认办结邮件入队，本机 SMTP 失败/重试测试使用隔离模拟接收器。

薪资催办固定为账单日前 3/2/1 个工作日，页面和 Excel 均不能修改节奏；前 3/2 天通知有效薪资账号，前 1 天升级给该客户对应业务员，已提交目标所属期后停止催办。月初收集通知与未提交催办分别处理。节假日与调休通过管理员日历维护，年度日历未维护时不能声称已按正式年度安排验收。账号开通通知不包含密码或令牌。

模板、签名、收件人与业务参数已有配置能力，接下来需要业务人员维护正式内容，不应继续列为尚未开发的功能。
