## 如何更新种子文件

修改 `backend/src/database/seeds/province-handler.seed.ts`：

```typescript
// Sheet4 湖北行
{ province: '湖北', handlerText: '朱敏/戴敏华' }
// ↓ 解析为
handlerUsernames: ['zhumin', 'daiminhua']
```

**拼音规则**：姓名拼音全拼，全小写，无分隔符。特殊多音字已标注。
