## 二、离职证明功能开发

### 2.1 子工单配置
- 在离职模块下新增"离职证明"子工单类型
- 复用原离职工单全部字段

### 2.2 流转条件判断逻辑
```
需要开具离职证明 == 是 AND 离职材料收集完成 == 是
  → 满足：流转到「离职证明开具」处理页面
  → 不满足（任一为否）：工单正常结束，不进入开具模块
```

### 2.3 实现要点
- 双条件AND关系判断
- 若无需收集材料，直接进入开具环节
- 开具环节由HR专员（杨纯+江璐）处理

## 四、在职证明开具系统

### 4.1 三级分类目录配置

#### 一级分类（4个）
1. **参保登记类**
   - 企业开户
   - 增减员
   - 补缴（应缴未缴补缴、基数调整差额补缴）
   - 调基
   - 退费（迟办减少退费、基数调整退费）
   - 信息变更（个人信息变更、单位信息变更）

2. **待遇类**
   - 退休代办
   - 病残津贴申请
   - 一次性支取
   - 生育待遇申请
   - 工伤认定
   - 工伤异地备案
   - 劳动能力鉴定
   - 工伤待遇申请
   - 失业金申领

3. **补贴类**
   - 个人补贴
   - 企业补贴

4. **其他**
   - 公积金转移
   - 职称认定

### 4.2 证明类型配置
- 在职证明
- 收入证明
- 社保证明
- 等其他证明类型

### 4.3 Word模板变量格式
- **占位符格式**：`{{变量名}}`
- 示例：`{{员工姓名}}`、`{{身份证号}}`、`{{入职日期}}`

### 4.4 动态字段渲染
- 根据证明类型加载对应的标准模板
- 动态替换模板中的变量占位符
- 支持Word格式导出
