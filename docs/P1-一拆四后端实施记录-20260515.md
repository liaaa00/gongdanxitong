# P1 一拆四后端实施记录（2026-05-15）

## 实施范围
- 入职拆分规则改为一拆四：`data_entry`、`social_insurance` 必生成，`onboarding_contact`、`contract` 继续按原条件生成。
- 不包含历史迁移、历史补数、历史回滚逻辑。
- 社保负责人不依赖“杨杰”账号存在，通过 `module_handlers`、`module_supervisors` 与 `handler_id = null` 模块池兜底。
- 新增字段级 dirty 标记，业务员修改主单字段时生成，负责人/主管/admin 打开子单详情或调用确认已阅接口时按子单清除 active dirty。
- 已完成子单退回仅允许模块主管或 admin，普通办理人完成后不可退回；退回原因必填，写审计记录。
- 社保公积金单个完成和批量完成均要求备注，错误信息中文可读。
- 补齐轻流式模块化配置最小闭环：模块、子模块、模块字段、字段权限、拆分规则、模块负责人、模块主管、导出模板、办理动作。

## 新增/变更接口清单
### 子单接口
- `GET /api/dispatched-orders/:id`
  - 已有接口增强：负责人/主管/admin 打开详情后清除该子单全部 active dirty。
  - 返回 `dirtyCount`、`clearedDirtyCount`，字段项返回 `dirty`、`dirtyInfo`。
- `GET /api/dispatched-orders?onlyDirty=true`
  - 新增按 active dirty 筛选。
- `POST /api/dispatched-orders/:id/dirty/confirm-read`
  - 显式确认已阅，按该子单清除全部 active dirty。
- `POST /api/dispatched-orders/:id/complete`
  - `social_insurance` 要求 `remark` 必填。
- `POST /api/dispatched-orders/:id/return`
  - 已完成子单只允许模块主管/admin；退回原因必填。
- `POST /api/dispatched-orders/social-insurance/batch-complete`
  - 入参：`{ ids: string[], remark: string }`。
  - 备注必填，中文错误：`社保批量完成备注必填，请填写月份、基数、操作类型等追溯信息`。
