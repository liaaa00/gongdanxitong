# 门户与工单系统对接收口计划

## 目标
在不改变现有工单正常派单、办理、回传规则的前提下，完成客户门户与工单系统的可验收闭环。

## 执行顺序

1. **现状冻结与风险检查**
   - 保留 D 盘主项目所有已有修改。
   - 读取当前分支、工作区差异、数据库迁移状态和服务端口。
   - 确认不执行 reset、clean、删库和生产操作。

2. **客户门户闭环补齐**
   - 补齐审核退回后的客户重新提交入口。
   - 仅允许客户修改退回字段，保留客户 UUID 和请求号绑定。
   - 重新提交后回到待审核状态，不自动绕过业务审核和派单。
   - 保留人工配置优先、附件门禁、字段契约校验和幂等规则。

3. **权限与页面验收**
   - 验证增减员合并权限 `employee_changes`。
   - 验证薪资独立权限 `salary`。
   - 验证业务员客户范围隔离、管理员范围和后道账号不可见。
   - 验证审核工作台、薪资工作台和门户页面布局。

4. **自动化验证**
   - 执行新增功能定向测试。
   - 执行前端、后端和门户构建。
   - 执行根目录 `回归测试.ps1`。
   - 修复普通测试错误，保留环境性警告记录。

5. **本机数据库和服务**
   - 确认 PostgreSQL `127.0.0.1:5433/ticket_system` 可用。
   - 运行迁移并确认无待执行项。
   - 从 D 盘启动后端、工单前端、客户门户和网关。

6. **真实数据端到端测试**
   - 使用本机真实数据库中的测试客户和账号。
   - 验证门户登录、字段契约、草稿、退回补正、重新提交、审核、派单、办理和结果回传。
   - 验证薪资跨客户列表、附件元数据和办结邮件队列。
   - 验证权限隔离和客户 UUID 绑定。
   - 只使用本机接收器/队列，不向真实联系人发送邮件。

7. **收口与报告**
   - 更新 `docs/AI修改记录.md` 和 `docs/业务规则回归清单.md`。
   - 保存测试日志和验证结果。
   - 汇报完成项、未完成外部配置和任何残余风险。

## 执行结果（2026-09-10）

计划第 1 至第 7 项已完成：D 盘主项目保留既有修改，门户与工单字段/权限/审核/薪资回传闭环已实现；数据库迁移无待执行项；后端、工单前端和客户门户构建通过；根目录固定回归、定向测试和真实本机端到端验证通过。当前仍待后续外部配置的只有正式 SMTP/API、正式门户网址、正式客户收件人和外部薪资系统对接，均未影响本机工单流转验收。
