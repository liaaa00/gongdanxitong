# 登录问题修复报告

## 问题概述
**症状**: 只有管理员账号（admin）可以登录，其他账号（包括种子用户和新创建的用户）都无法登录。

**根本原因**: `ensureSeedPasswords()` 函数逻辑缺陷 - 只要 localStorage 中存在任何密码条目，就不会为缺少密码的种子用户创建密码。

## 修复内容

### 1. 核心修复
**文件**: `frontend/src/services/users.ts`

修改了 `ensureSeedPasswords()` 函数，从"全有或全无"改为"按需补充"：
- ✅ 检查每个种子用户是否有密码
- ✅ 只为缺少密码的用户创建密码条目
- ✅ 保留已存在的密码条目

### 2. 诊断工具
**文件**: `frontend/src/utils/diagnoseAuth.ts`

提供浏览器控制台命令：
- `diagnoseAuth()` - 诊断用户和密码匹配情况
- `fixAuth()` - 自动为缺少密码的用户创建默认密码

### 3. 单元测试
**文件**: `frontend/src/services/users.test.ts`

测试覆盖：

- ✅ 新用户创建和登录
- ✅ 错误密码拒绝

## 技术细节

### 修复前的问题逻辑
```typescript
function ensureSeedPasswords() {
  const existing = loadPasswords();
  if (existing.length > 0) return;  // ❌ 只要有任何密码就返回
  // 创建所有种子密码...
}
```

### 修复后的正确逻辑
```typescript
function ensureSeedPasswords() {
  const existing = loadPasswords();
  const existingUsernames = new Set(existing.map(p => p.username));
  
  // ✅ 检查每个种子用户
  const missingPasswords: PasswordEntry[] = [];
  for (const [username, password_hash] of Object.entries(DEFAULT_SEED_PASSWORDS)) {
    if (!existingUsernames.has(username)) {
      missingPasswords.push({ username, password_hash });
    }
  }
  
  // ✅ 只添加缺失的密码
  if (missingPasswords.length > 0) {
    const updated = [...existing, ...missingPasswords];
    savePasswords(updated);
  }
}
```
