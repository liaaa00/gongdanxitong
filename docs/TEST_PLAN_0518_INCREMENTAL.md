## 5. 角色权限测试矩阵

| 角色 | 仪表盘范围 | 左侧菜单 | 我的工单 | 操作权限 | 管理配置 |

1. 菜单是否可见。
2. 路由 URL 直达是否被拦截。
3. API 是否返回 403/409，避免仅前端隐藏。
4. 列表数据范围是否正确，避免跨角色/跨模块泄露。
