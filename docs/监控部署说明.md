# 监控部署说明

## 组件

- Prometheus：抓取后端 `/api/metrics`，默认保留 15 天。
- Grafana：自动配置 Prometheus 数据源和 `Ticket System Overview` 看板。
- 告警规则：后端不可用、5xx 比例超过 5%、P95 延迟超过 2 秒。

指标端点仅允许 Docker 内部 Prometheus 直接访问，业务 Nginx 对 `/api/metrics` 返回 404。

## 启动

生产部署前必须在 `.env` 设置强密码：

```text
GRAFANA_ADMIN_PASSWORD=<strong-password>
```

启动完整服务：

```powershell
docker compose up -d --build
```

默认地址：

- Prometheus：`http://127.0.0.1:9090`
- Grafana：`http://127.0.0.1:3001`

默认只监听本机。确需从局域网访问时，显式调整 `PROMETHEUS_BIND_ADDRESS` 或 `GRAFANA_BIND_ADDRESS`，并同时配置网络访问控制。

## 验证

```powershell
docker compose config
docker compose ps
docker compose exec prometheus promtool check config /etc/prometheus/prometheus.yml
docker compose exec prometheus promtool check rules /etc/prometheus/alerts.yml
Invoke-WebRequest http://127.0.0.1:9090/-/healthy -UseBasicParsing
Invoke-WebRequest http://127.0.0.1:3001/api/health -UseBasicParsing
```
