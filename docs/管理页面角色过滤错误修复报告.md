# 管理页面角色过滤错误修复报告

## 问题描述

用户在成功运行系统后，点击管理页面时出现错误：

```
Something went wrong.
allRoles.filter is not a function
```

## 根本原因

### 后端返回格式

后端 `roles.service.ts` 的 `list()` 方法返回的是**分页对象**：

```typescript
{
  page: 1,
  pageSize: 20,
  total: 15,
  totalPages: 1,
  list: [角色数组]  // 数据在 list 字段中
}
```

这是通过 `toPageResult()` 函数生成的标准分页响应格式（定义在 `backend/src/common/types/pagination.types.ts`）。

### 前端期望格式

前端代码在以下两个文件中直接将 `getRoles()` 的返回值当作数组使用：

1. **`frontend/src/pages/Admin/Roles/index.tsx:78`**
   ```typescript
   const data = await getRoles();
   setAllRoles(data);  // data 实际上是分页对象，不是数组
   ```

2. **`frontend/src/pages/Admin/Users/index.tsx:60`**
   ```typescript
   const allRoles = await getRoles();
   const rolesMap = new Map(allRoles.map(r => [r.id, r]));  // 对象没有 map 方法
   ```

当代码尝试调用 `allRoles.filter()` 时，因为 `allRoles` 是一个对象而不是数组，所以报错。

## 解决方案

### 修复文件

修改了以下两个文件，正确提取分页对象中的 `list` 字段：

#### 1. `frontend/src/pages/Admin/Roles/index.tsx`

```typescript
request={async () => {
  const result = await getRoles();
  // 后端返回分页对象 { list, total, page, pageSize }
  const data = Array.isArray(result) ? result : (result as any).list || [];
  setAllRoles(data);
  return { data, success: true, total: data.length };
}}
```

#### 2. `frontend/src/pages/Admin/Users/index.tsx`

修改了三处使用 `getRoles()` 的地方：

```typescript
// 在 openCreate 函数中
const result = await getRoles();
const roles = Array.isArray(result) ? result : (result as any).list || [];
setRoleOptions(flattenRoles(roles));

// 在 openEdit 函数中
const result = await getRoles();
const roles = Array.isArray(result) ? result : (result as any).list || [];
setRoleOptions(flattenRoles(roles));

// 在 onSave 函数中
const result = await getRoles();
const allRoles: RoleItem[] = Array.isArray(result) ? result : (result as any).list || [];
const rolesMap = new Map(allRoles.map((r: RoleItem) => [r.id, r]));
```

同时添加了 `RoleItem` 类型导入以修复 TypeScript 类型错误。
