## 3. 问题清单（路C：复现 / 预期 / 实际 / 报错 / 是否前端修复）

### P0-01 导出模板页崩溃：`rawData.some is not a function`

- 页面：`/export-templates`
- 复现步骤：
  1. 打开 Chrome。
  2. 登录 `lizhanbo/admin123`。
  3. 访问 `/export-templates`。
- 预期：导出模板列表正常展示；即使无数据也显示空状态。
- 实际：页面触发表格运行时错误；部分情况下被 ErrorBoundary 捕获，用户看到异常页。
- 控制台报错：
  - `pageerror: rawData.some is not a function`
  - `The above error occurred in the <ForwardRef(InternalTable)> component`
- 网络报错：无 5xx；接口本身 200。
- 代码位置推测：
  - 前端：`frontend/src/pages/ExportTemplates/index.tsx`
  - 服务：`frontend/src/services/exportTemplates.ts`
  - 后端接口：`GET /api/admin/export-templates`
- 根因推测：
  - 后端返回分页对象：`{ page, pageSize, total, totalPages, list: [...] }`。
  - 前端 `getExportTemplates()` 声明/使用期望直接返回 `ExportTemplateItem[]`。
  - `ProTable` 的 `request` 中 `const result = await getExportTemplates(...); return { data: result, total: result.length }`，导致 `data` 变成对象，AntD Table 内部调用 `rawData.some` 崩溃。
- 是否需前端修复：是。
- 建议：`getExportTemplates` 统一适配 `items/list` 分页返回；或页面中 `const list = Array.isArray(result) ? result : result.list ?? result.items ?? []`。

### P0-02 管理后台字段配置页崩溃：Table dataSource 非数组

  - 栈：`InternalTable -> Table -> PageContainer -> AdminFields`

  - 服务：`frontend/src/services/fields.ts`

## 4. P2 体验/告警问题

### P2-01 ProLayout 菜单重复 key

- 现象：几乎所有页面控制台出现：
  - `Warning: Duplicated key '/work-orders' used in Menu`
  - `Warning: Duplicated key '/my-dispatched' used in Menu`
  - `Warning: Duplicated key '/renewal' used in Menu`
  - `Warning: Duplicated key '/resignation' used in Menu`
  - `Warning: Duplicated key '/benefit' used in Menu`
- 代码位置：`frontend/src/layouts/BasicLayout.tsx`
- 根因：父菜单 path 与第一个子菜单 path 相同。
- 建议：父级使用唯一 path/key，例如 `/work-orders/_group` 或显式 `key`，点击父级时再跳转到默认子页面。

### P2-02 AntD / ProTable `findDOMNode` 严格模式告警

- 页面：所有使用 ProTable 工具栏/Tooltip/Dropdown 的页面。
- 实际：控制台大量 `findDOMNode is deprecated`。
- 代码位置：主要来自 `@ant-design/pro-components`/AntD 内部，业务侧可减少 StrictMode 或升级依赖验证。
- 严重性：不阻塞演示，但会淹没真正错误日志。

### P2-03 静态 message API 告警

- 现象：`Warning: [antd: message] Static function can not consume context like dynamic theme. Please use 'App' component instead.`
- 页面：入职发起、详情错误提示、新建页等。
- 代码位置：搜索 `message.` 静态调用，改用 `App.useApp()`。
- 严重性：体验/日志污染。

### P2-04 角色 code 命名不一致，可能造成权限体验异常

- 现象：后端真实账号返回角色如 `biz_manager`、`biz_leader`、`biz_member`、`onboarding_specialist`、`contract_specialist`；前端 `RoleRoute` 期望 `business_owner`、`business_group_leader`、`shared_team_owner`、`labor_contract_member` 等。
- 代码位置：`frontend/src/routes/index.tsx`、`frontend/src/layouts/BasicLayout.tsx`、后端 seed/角色定义。
- 风险：非管理员可能看到不该看的菜单或访问团队页被错误 403。
- 建议：前后端统一角色 code，或前端增加兼容映射。
