## 【进行中 / 待解决的 Bug】⚠️

### 已知隐患
1. **多分支未合并**：项目中存在多个 git worktree / 分支，部分改动可能重复或冲突。
2. **`spectrai-worktrees/` 目录**：存在 `.spectrai-worktrees/` 目录，可能是历史 AI 会话遗留物，需清理确认。
3. **旧种子代码兼容**：后端角色种子使用了旧代码（如 `biz_manager`、`biz_leader`），前端通过 `BACKEND_TO_CANONICAL` 映射兼容。如果后端种子重新执行，可能产生不一致。
4. **双密码库**：`bcrypt` 和 `bcryptjs` 同时存在于 `package.json`，理论上只需一个。
5. **backend `package.json` 中 `@nestjs/axios` v4.0.1 但安装的是 v3.1.3**：caret 回退导致的版本不一致，属于已知 npm 解析现象。
6. **社交催办字段**：存在 `disable`/`restore` 的 migration 循环（20260520002000 + 20260520004000），表明该字段历史上被反复启停。

### 边缘情况
7. **Pool 策略子工单**：公共池认领后的并发竞态未充分测试。
8. **AI 字段映射降级**：当 OpenAI 不可用时，降级到手动映射的体验需进一步验证。
9. **大文件导入**：5000 行上限一次性导入时的事务超时未测试。
10. **SLA 提醒**：SLA 超时提醒的 Cron 任务在极端情况下可能重复触发。
