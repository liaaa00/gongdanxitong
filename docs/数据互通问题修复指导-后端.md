## 一、问题概述

当前后端配置导致其他电脑无法访问数据库和API：
- 数据库监听地址：`127.0.0.1`（仅本机）
- PostgreSQL默认配置：仅允许本地连接

**目标**：让局域网内的其他电脑能够访问后端API和数据库。

---

## 二、修复步骤

### 步骤1：修改后端环境变量

```powershell
# 1. 打开后端配置文件
cd D:\AI\SpeceAppDate\工单系统\backend
notepad .env
```

**修改内容**：
```env
# 修改前：
DB_HOST=127.0.0.1

# 修改后：
DB_HOST=0.0.0.0
```

**说明**：
- `0.0.0.0` 表示监听所有网络接口
- 允许通过局域网IP访问数据库

---

### 步骤2：配置PostgreSQL监听地址

```powershell
# 2. 编辑PostgreSQL配置文件
cd D:\AI\SpeceAppDate\工单系统\tools\pgsql16\data
notepad postgresql.conf
```

**查找并修改**：
```conf
# 查找这一行（约在第59行）
#listen_addresses = 'localhost'

# 修改为：
listen_addresses = '*'
```

**说明**：
- `*` 表示监听所有IP地址
- 允许远程连接

---

### 步骤3：配置PostgreSQL访问控制

```powershell
# 3. 编辑访问控制文件
notepad pg_hba.conf
```

**在文件末尾添加**：
```conf
# 允许局域网192.168.26.0/24网段访问
host    all    all    192.168.26.0/24    md5

# 如果不确定网段，可以临时允许所有IP（不推荐生产环境）
# host    all    all    0.0.0.0/0    md5
```

**说明**：
- `192.168.26.0/24`：允许192.168.26.1-254的所有IP
- `md5`：使用密码认证
- 根据实际网络环境调整网段

---

### 步骤4：重启PostgreSQL

```powershell
# 4. 停止PostgreSQL
cd D:\AI\SpeceAppDate\工单系统\tools\pgsql16
.\stop-pg.ps1

# 等待3秒

# 5. 启动PostgreSQL
.\start-pg.ps1

# 6. 验证PostgreSQL已启动
.\tools\pgsql16\bin\psql.exe -U ticket -d ticket_system -c "SELECT version();"
```

**预期输出**：
```
PostgreSQL 16.x on x86_64-pc-windows-msvc, compiled by ...
```

---

### 步骤5：配置后端CORS

```powershell
# 7. 编辑后端主文件
cd D:\AI\SpeceAppDate\工单系统\backend\src
notepad main.ts
```

**查找 `app.enableCors()` 并修改**：
```typescript
// 修改前（如果存在）：
app.enableCors();

// 修改后：
app.enableCors({
  origin: [
    'http://localhost:5173',           // 本地开发
    'http://192.168.26.66:5173',       // 局域网访问
    'http://192.168.26.66',            // Nginx代理
  ],
  credentials: true,
  methods: ['GET', 'POST', 'PUT', 'DELETE', 'PATCH', 'OPTIONS'],
  allowedHeaders: ['Content-Type', 'Authorization'],
});
```

**说明**：
- 允许前端从不同域名访问API
- `credentials: true`：允许携带Cookie和认证信息

---

### 步骤6：重启后端服务

```powershell

# 9. 重新启动
cd D:\AI\SpeceAppDate\工单系统\backend
pnpm start:dev
```

**预期输出**：
```
[Nest] 12345  - 2026/05/13 14:30:00     LOG [NestApplication] Nest application successfully started
[Nest] 12345  - 2026/05/13 14:30:00     LOG [NestApplication] Application is running on: http://[::]:3000
```

### 步骤7：配置Windows防火墙

```powershell

netsh advfirewall firewall add rule name="工单系统后端API" dir=in action=allow protocol=TCP localport=3000

# 11. 允许5432端口（PostgreSQL）

```

**验证防火墙规则**：
```powershell
netsh advfirewall firewall show rule name="工单系统后端API"
netsh advfirewall firewall show rule name="工单系统PostgreSQL"
```

## 四、常见问题排查

### 问题1：PostgreSQL启动失败

**症状**：
```
could not bind IPv4 address "0.0.0.0": Permission denied
```

**解决方案**：
```powershell
# 以管理员身份运行PowerShell
# 重新执行启动脚本
.\tools\pgsql16\start-pg.ps1
```

---

### 问题2：其他电脑无法连接数据库

**症状**：
```
psql: error: connection to server at "192.168.26.66", port 5432 failed: timeout
```

**排查步骤**：
1. 检查防火墙规则是否生效
2. 检查PostgreSQL是否监听5432端口
   ```powershell
   netstat -an | findstr 5432
   ```
3. 检查pg_hba.conf配置是否正确
4. 尝试临时关闭防火墙测试
   ```powershell
   netsh advfirewall set allprofiles state off
   ```

---

### 问题3：CORS错误

**症状**：
```
Access to XMLHttpRequest at 'http://192.168.26.66:3000/api/...' from origin 'http://192.168.26.66:5173' has been blocked by CORS policy
```

**解决方案**：
1. 确认 `main.ts` 中的CORS配置包含前端域名
2. 重启后端服务
3. 清除浏览器缓存

---

### 问题4：数据库连接池耗尽

**症状**：
```
Error: Connection pool exhausted
```

**解决方案**：
```typescript
// backend/src/database/database.module.ts
TypeOrmModule.forRoot({
  // ...其他配置
  extra: {
    max: 20,  // 增加连接池大小
    min: 5,
  },
}),
```

## 五、安全建议

### 生产环境配置

1. **不要使用0.0.0.0监听公网**
   ```env
   # 仅监听局域网IP
   DB_HOST=192.168.26.66
   ```

2. **限制pg_hba.conf访问范围**
   ```conf
   # 仅允许特定IP段
   host    all    all    192.168.26.0/24    md5
   ```

3. **使用强密码**
   ```env
   DB_PASSWORD=your-strong-password-here
   JWT_SECRET=your-production-jwt-secret-here
   ```

4. **启用SSL/TLS**
   ```typescript
   // backend/src/main.ts
   const httpsOptions = {
     key: fs.readFileSync('./secrets/private-key.pem'),
     cert: fs.readFileSync('./secrets/public-certificate.pem'),
   };
   const app = await NestFactory.create(AppModule, { httpsOptions });
   ```
