## ✅ 已完成修复

### 问题3：同意修改后状态变成已退回

**状态**：✅ 已修复

**问题描述**：后道人员点"同意修改"后，工单状态变成"已退回"而非"处理中"

**根本原因**：
`backend/src/modules/dispatched-orders/dispatched-order.service.ts` 第843行，批准修改后将状态设为 `PENDING`（未接单）而非 `PROCESSING`（已接单）

**修复内容**：
```typescript
// 修改前
order.status = shouldRedispatch ? DispatchedOrderStatus.PENDING : previousStatus;
order.acceptedAt = shouldRedispatch ? null : order.acceptedAt;

// 修改后
order.status = shouldRedispatch ? DispatchedOrderStatus.PROCESSING : previousStatus;
order.acceptedAt = shouldRedispatch ? (order.acceptedAt || new Date()) : order.acceptedAt;
```

**修改文件**：
- `backend/src/modules/dispatched-orders/dispatched-order.service.ts`（843-844行）

**验证方法**：
1. 创建工单并派发
2. 后道人员退回工单
3. 业务员申请修改
4. 后道人员批准修改
5. 确认工单状态为"已接单/处理中"而非"未接单"
