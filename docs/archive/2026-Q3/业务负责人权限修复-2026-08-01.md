## 影响范围

### 受影响的路由
`BUSINESS_ORDER_ROLES` 常量用于以下路由的权限配置：

1. **主工单列表**
   - `/work-orders` - 主工单列表页
   - `/work-orders/:id` - 主工单详情页

2. **省外业务**（通过 `OUT_OF_PROVINCE_ROLES = BUSINESS_ORDER_ROLES`）
   - `/out-of-province` - 省外增减员列表
   - `/out-of-province/*` - 所有省外业务子路由

### 业务负责人新增权限

修改后，业务负责人（`business_owner` / `biz_manager`）将能够访问：

#### ✅ 新增可访问路由
- `/work-orders` - 主工单列表
- `/work-orders/:id` - 主工单详情
- `/out-of-province` - 省外增减员列表
- `/out-of-province/import` - 省外批量导入
- `/out-of-province/new` - 新建省外工单
- `/out-of-province/increase` - 省外增员
- `/out-of-province/decrease` - 省外减员
- `/out-of-province/single-business` - 省外单项业务
- `/out-of-province/orders` - 省外派单列表
- `/out-of-province/orders/:id` - 省外派单详情

#### ✅ 原有可访问路由（不变）
- `/dashboard` - 仪表盘
- `/dashboards/leader` - 领导看板
- `/my-dispatched/:id` - 子工单详情
- `/in-service/*` - 在职管理全部路由
- `/in-service/:id/audit` - 在职工单审批

## 操作权限说明

### ⚠️ 重要：路由访问 ≠ 操作权限

**业务负责人虽然能访问主工单列表，但不能进行操作！**

根据后端权限清单（`backend/角色权限清单-基线.md`），业务负责人（`biz_manager`）的权限：

#### ✅ 拥有的权限（5个）
- `work_order.view_all` - 查看所有工单（只读）
- `work_order.export` - 导出数据
- `route.dashboard` - 访问仪表盘
- `route.dispatched_detail` - 访问子工单详情
- `route.leader_dashboard` - 访问领导看板

#### ❌ 没有的权限
- `work_order.create` - 新建工单
- `work_order.import` - 批量导入
- `work_order.update` - 修改工单
- `work_order.delete` - 删除工单
- `work_order.withdraw` - 撤回工单
- `work_order.void` - 作废工单

### 前端自动隐藏操作按钮

在主工单列表页面，前端会根据后端权限自动隐藏操作按钮：

```typescript
// 前端组件中的权限判断示例
const { hasPermission } = useAuth();

// 新建按钮 - 业务负责人看不到
{hasPermission(['work_order.create']) && <Button>新建</Button>}

// 导出按钮 - 业务负责人可以看到
{hasPermission(['work_order.export']) && <Button>导出</Button>}
```

**实际效果**：
- 业务负责人能看到主工单列表
- 能查看工单详情
- 能导出数据
- 但看不到"新建"、"导入"、"修改"、"删除"等操作按钮
