# 登录问题排查指南

## 问题现象
只有管理员账号（admin）可以登录，其他账号（包括自己创建的账号）都无法登录。

## 快速解决方案

### 方案一：清理浏览器缓存（推荐）

1. **打开浏览器开发者工具**
   - 按 `F12` 或右键点击页面选择"检查"

2. **清理 localStorage**
   - 切换到 `Application` 或 `存储` 标签
   - 左侧找到 `Local Storage` → 选择你的网站地址
   - 右键点击 → 选择 `Clear` 或 `清除`
   - 或者在 Console 中执行：
     ```javascript
     localStorage.clear()
     ```

3. **刷新页面**
   - 按 `Ctrl + F5` 强制刷新页面
   - 重新登录

### 方案二：使用浏览器控制台重置密码

1. **打开浏览器控制台**（F12 → Console）

2. **执行以下代码重置所有种子用户密码**：
   ```javascript
   // 重置所有种子用户的密码
   const passwords = {
     lizhanbo: '123456',
     wangzixi: '123456',
     aolei: '123456',
     yaoyiping: '123456',
     annazhen: '123456',
     jianglu: '123456',
     yangchun: '123456',
     maoyani: '123456',
     admin: '123456'
   };
   
   const entries = Object.entries(passwords).map(([username, password_hash]) => ({
     username,
     password_hash
   }));
   
   localStorage.setItem('mock_admin_passwords_v1', JSON.stringify(entries));
   console.log('✅ 密码已重置，请刷新页面后重新登录');
   ```

3. **刷新页面并登录**

### 方案三：检查密码状态

在浏览器控制台执行以下代码，查看当前密码存储状态：

```javascript
// 查看所有用户
const users = JSON.parse(localStorage.getItem('mock_admin_users_v1') || '[]');
console.log('📋 用户列表：', users.map(u => u.username));

// 查看密码记录
const passwords = JSON.parse(localStorage.getItem('mock_admin_passwords_v1') || '[]');
console.log('🔑 密码记录：', passwords);

// 检查哪些用户没有密码
const usersWithoutPassword = users.filter(u => 
  !passwords.find(p => p.username === u.username)
);
console.log('⚠️ 没有密码的用户：', usersWithoutPassword.map(u => u.username));
```

## 新创建用户无法登录

如果你创建的新用户无法登录，请检查：

1. **创建用户时是否设置了密码**
   - 新建用户表单中有"密码"字段（必填，至少6位）
   - 如果没有看到密码字段，说明代码可能不是最新版本

2. **检查新用户的密码是否保存**
   ```javascript
   // 查看所有密码记录
   const passwords = JSON.parse(localStorage.getItem('mock_admin_passwords_v1') || '[]');
   console.log('所有密码记录：', passwords);
   ```

3. **手动为新用户设置密码**
   ```javascript
   // 替换 'your_username' 和 'your_password'
   const username = 'your_username';
   const password = 'your_password';
   
   const passwords = JSON.parse(localStorage.getItem('mock_admin_passwords_v1') || '[]');
   const idx = passwords.findIndex(p => p.username === username);
   
   if (idx >= 0) {
     passwords[idx].password_hash = password;
   } else {
     passwords.push({ username, password_hash: password });
   }
   
   localStorage.setItem('mock_admin_passwords_v1', JSON.stringify(passwords));
   console.log(`✅ 已为用户 ${username} 设置密码`);
   ```

## 常见问题

### Q1: 为什么清理缓存后就能登录了？
**A:** 系统使用 localStorage 存储 Mock 数据。如果之前的代码版本有 bug，旧数据会一直保留。清理缓存后，系统会重新初始化正确的数据。

### Q2: 每次刷新页面都要重新登录？
**A:** 不应该。登录状态保存在 localStorage 中。如果每次都要重新登录，可能是：
- 浏览器隐私模式
- 浏览器设置了自动清理 localStorage
- 代码有 bug

### Q3: 修改用户密码后无法登录？
**A:** 在用户管理页面修改密码时，新密码会自动保存到 localStorage。如果修改后无法登录，可能是：
- 页面没有刷新
- localStorage 数据损坏（使用方案二重置）

### Q4: 如何确认代码是最新版本？
**A:** 检查以下文件：
1. `frontend/src/services/auth.ts` 第47行应该是：
   ```typescript
   const user = validateUserCredentials(data.username, data.password);
   ```
2. `frontend/src/services/users.ts` 应该有 `validateUserCredentials` 函数
3. `frontend/src/pages/Admin/Users/index.tsx` 新建用户表单应该有密码输入框（第143-154行）

## 技术说明

当前系统使用 **Mock 模式**进行演示，所有数据存储在浏览器的 localStorage 中：

- `mock_admin_users_v1`：用户列表
- `mock_admin_passwords_v1`：密码记录（明文存储，仅用于演示）
- `mock_session_user_v1`：当前登录用户信息

**注意**：这是演示模式，生产环境会使用真实的后端 API 和数据库，密码会使用 bcrypt 加密存储。
