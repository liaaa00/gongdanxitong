# 劳动合同续签与证明开具测试前说明

> 适用对象：业务员、业务组长、业务负责人和参与联调的后道办理人员
> 当前口径：2026-08-21
> 测试范围：北仑账套的“劳动合同续签”和“证明开具”

## 1. 先了解整体规则

这两个功能是“在职管理”下的独立业务，不再作为入职主工单的子工单发起，也不需要进入“单项业务办理”：

- **劳动合同续签**：业务侧发起续签资料，合同办理人员接单、导出续签合同模板并完成。
- **证明开具**：业务侧发起在职证明或收入证明，证明办理人员开具标准 DOCX 并完成。
- 两个功能的流程、状态和详情页面相互独立，测试时不要把续签单和证明单混在同一个业务流程里。
- 流程配置由管理员在后台维护；业务员只按页面显示的字段和按钮操作，页面红色 `*` 与提交时后端校验均为最终口径。

## 2. 入口和测试账号

登录后进入左侧 **在职管理**：

- **劳动合同续签**
- **证明开具**

业务员/业务组长/管理员可以发起新单；实际接单和办理按钮只对被配置的办理人、主管或管理员显示。看不到菜单或详情时，先确认账号角色和业务范围，不要直接判断为数据丢失。

测试时建议使用专门的测试客户和测试员工资料，避免使用真实员工身份证号重复提交。

## 3. 劳动合同续签

### 3.1 发起时系统如何带数

1. 先选择客户，再填写员工姓名和证件号。
2. 系统按“客户 + 证件号”查询本系统最近的入职/续签历史。
3. 找到历史时：
   - 自动带出员工历史资料；
   - 自动继承历史发起部门，发起部门不可随意改；
   - 合同主体、岗位等历史字段会作为默认值或只读值使用。
4. 查不到历史时：
   - 必须手工选择该存量员工所属的发起部门；
   - 不会默认使用当前登录人的部门；
   - 业务员需要补齐页面显示的合同资料后再提交。

### 3.2 当前必填和条件必填

必填规则以页面红色 `*` 为准，核心规则如下：

- 合同期限形式：必填。
- 合同开始日期：必填。
- 基本工资：必填。
- 选择“无固定期限”时：合同期限、合同终止日期可以不填。
- 选择其他期限形式时：合同期限、合同终止日期必须填写。
- 需要电子签时：必须选择电子签平台；选择 E 签宝时，劳动合同主体注册地必须有值。
- 选择劳动合同主体后，系统会自动带出主体注册地；不要手工改写自动带出的地址。
- 试用期在续签中不是默认必填，可以按实际业务留空。
- 岗位、岗位类型等历史字段可能以只读方式显示；这是为了避免续签时误改历史路由资料。

页面还会根据当前后台字段配置显示手机号、工作城市、工时制、工资形式、合同模板等字段；提交前请按页面提示补齐，不要使用旧 Excel 字段清单代替当前页面。

### 3.3 续签状态和办理动作

正常流程：

`未接单 → 已接单 → 已完成`

- 业务员提交后，列表先显示“未接单”。
- 办理人员点击“接单”后变为“已接单”。
- 办理人员核对资料、需要时导出“续签合同模板”，完成后点击“完成”。
- 续签不显示材料确认、线上/线下办理、办理失败或转派按钮。

资料不完整时：

- 办理人员点击“退回”，填写退回原因；
- 业务员看到“已退回”，进入详情修改并点击“补充材料并提交”；
- 重新提交必须填写原因，状态会回到退回前的办理节点。

业务员在未完成前可以按权限“撤回工单”或“作废工单”；已完成工单不能再走这两个动作。

### 3.4 续签导出测试

在续签详情点击 **导出续签模板**：

- 只有办理人、主管或管理员可导出；
- 需要电子签的平台信息完整，系统才会按速创/E 签宝模板规则导出；
- 导出的文件名类似 `劳动合同续签-工单号.xlsx`；
- 重点检查员工姓名、证件号、合同起止日期、期限形式、基本工资、合同主体和电子签平台是否与详情一致。

## 4. 证明开具

### 4.1 发起时要填写什么

当前可选证明类型：

- **在职证明**
- **收入证明**
- **社保证明暂不可选**，因为标准模板尚未配置，不要用其他证明类型替代。

发起页面必填：

- 客户；
- 员工姓名；
- 证件号；
- 证明类型；
- 入职日期；
- 职务；
- 证明用途。

填写客户和证件号后，系统会尝试从历史入职/续签记录带出入职日期、职务和基本工资参考。历史资料只是默认值，业务员需要核对后再提交；查询失败不会阻断证明发起。

收入证明的“近一年税前月均收入”由办理人员在完成证明时确认，发起时不需要业务员填写最终值。

### 4.2 证明状态和办理动作

正常流程：

`待开具 → 开具中 → 已完成`

- 业务员提交后，办理人员点击“开始开具”，状态变为“开具中”。
- 办理人员完成文档制作后点击“完成开具”。
- 收入证明完成时，必须在完成弹窗填写大于 0 的“近一年税前月均收入”；在职证明不需要该项。
- 证明开具不显示材料确认、线上/线下办理或办理失败按钮，但支持按权限转派。

需要补充资料时：

- 办理人员点击“需补充材料”并填写原因；
- 业务员看到“已退回”，补齐信息后点击“补充材料并提交”；
- 重新提交必须填写原因，状态回到退回前的节点。

### 4.3 证明导出测试

办理人员在详情点击 **导出标准模板**：

- 在职证明生成标准在职证明 DOCX；
- 收入证明生成标准收入证明 DOCX，并带入已确认的月均收入；
- 社保证明导出会被系统拒绝，属于当前明确限制；
- 重点检查姓名、证件号、入职日期、职务、证明用途，收入证明另检查月均收入。

## 5. 建议的测试顺序

### 续签最小闭环

1. 业务员新建一条有历史记录的续签单，确认部门和历史资料自动带出。
2. 再新建一条无历史记录的续签单，确认必须选择发起部门。
3. 分别测试“固定期限”和“无固定期限”的条件必填。
4. 提交后用办理人员账号接单，检查状态和详情。
5. 导出续签模板，核对 Excel 内容。
6. 办理人员退回一次，业务员补充后重新提交，确认状态恢复。
7. 最后完成，确认状态为“已完成”。

### 证明最小闭环

1. 新建一条在职证明，核对历史默认值和必填项。
2. 办理人员点击“开始开具”，再导出并完成。
3. 新建一条收入证明，在“完成开具”时填写月均收入并检查 DOCX。
4. 测试一次“需补充材料 → 业务员补充并重新提交”。
5. 确认社保证明不可选/不可导出，不把它当作故障。

## 6. 发现问题时请记录

反馈问题时请同时提供：

- 测试账号和业务范围；
- 工单号；
- 当前页面显示状态；
- 点击的按钮和完整提示；
- 是否为历史带数、固定期限/无固定期限、在职证明/收入证明；
- 截图或导出的文件。

不要只反馈“提交不了”或“看不到数据”，否则无法判断是权限、必填校验、状态节点还是模板配置问题。
