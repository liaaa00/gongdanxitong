# 数据互通问题 - 5分钟快速修复指南

**问题**：同一管理员账号在两台电脑登录，数据不一致  
**根因**：前端Mock模式 + 数据库本地地址配置  
**修复时间**：5分钟  
**适用场景**：紧急修复，立即让两台电脑看到相同数据

---

## 🚀 快速修复步骤

### 第一步：修改前端Mock模式判断（1分钟）

```powershell
# 打开文件
notepad D:\AI\SpeceAppDate\工单系统\frontend\src\services\mock.ts
```

**找到第1行，修改为**：
```typescript
export const isMockMode = import.meta.env.VITE_USE_MOCK === 'true';
```

**保存并关闭**。

---

### 第二步：修改前端API地址（1分钟）

```powershell
# 打开文件
notepad D:\AI\SpeceAppDate\工单系统\frontend\.env
```

**修改为**：
```env
VITE_USE_MOCK=false
VITE_API_BASE_URL=http://192.168.26.66:3000
```

**保存并关闭**。

---

### 第三步：修改后端数据库地址（1分钟）

```powershell
# 打开文件
notepad D:\AI\SpeceAppDate\工单系统\backend\.env
```

**找到 `DB_HOST`，修改为**：
```env
DB_HOST=0.0.0.0
```

**保存并关闭**。

---

### 第四步：配置PostgreSQL（1分钟）

```powershell
# 打开文件
notepad D:\AI\SpeceAppDate\工单系统\tools\pgsql16\data\postgresql.conf
```

**找到 `listen_addresses`（约第59行），修改为**：
```conf
listen_addresses = '*'
```

**保存并关闭**。

```powershell
# 打开文件
notepad D:\AI\SpeceAppDate\工单系统\tools\pgsql16\data\pg_hba.conf
```

**在文件末尾添加**：
```conf
host    all    all    192.168.26.0/24    md5
```

**保存并关闭**。

---

### 第五步：重启服务（1分钟）

```powershell
# 1. 重启PostgreSQL
cd D:\AI\SpeceAppDate\工单系统\tools\pgsql16
.\stop-pg.ps1
.\start-pg.ps1

# 2. 重启后端（先停止当前运行的，Ctrl+C）
cd D:\AI\SpeceAppDate\工单系统\backend
pnpm start:dev

# 3. 重新构建前端（新开一个终端）
cd D:\AI\SpeceAppDate\工单系统\frontend
pnpm build
pnpm preview
```

---

### 第六步：配置防火墙（30秒）

```powershell
# 允许3000端口（后端）
netsh advfirewall firewall add rule name="工单系统API" dir=in action=allow protocol=TCP localport=3000

# 允许5173端口（前端）
netsh advfirewall firewall add rule name="工单系统前端" dir=in action=allow protocol=TCP localport=5173
```

## 🆘 常见问题

### 问题1：电脑B无法访问

**解决**：
```powershell
# 在电脑A执行
ping 192.168.26.66  # 确认IP正确
netstat -an | findstr 3000  # 确认后端在运行
netstat -an | findstr 5173  # 确认前端在运行
```

### 问题2：CORS错误

**解决**：
```powershell
# 编辑 backend/src/main.ts
# 找到 app.enableCors()，修改为：
app.enableCors({
  origin: ['http://192.168.26.66:5173', 'http://192.168.26.66'],
  credentials: true,
});

# 重启后端
```

### 问题3：仍在Mock模式

**解决**：
```powershell
# 完全清理并重新构建
cd D:\AI\SpeceAppDate\工单系统\frontend
Remove-Item -Recurse -Force dist
Remove-Item -Recurse -Force node_modules/.vite
pnpm build
pnpm preview

# 浏览器硬刷新（Ctrl+F5）
```
