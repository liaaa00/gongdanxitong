## 一、权限配置概述

### 1.1 权限模式 (FieldPermissionMode)
- **visible**: 可见可编辑
- **readonly**: 只读
- **hidden**: 隐藏
- **masked**: 脱敏显示（身份证号、手机号、银行卡号）

## 三、场景权限配置规则

### 3.1 创建场景 (create:*)

#### 场景: create:onboarding (创建入职工单)
**权限计算函数**: `createPermission(roleCode, field, [ONBOARDING])`

**规则**:
- **admin**: 全部字段 **visible**
- **BUSINESS_ROLE_CODES**: 属于 ONBOARDING 业务域的字段 **visible**
- **其他角色**: 属于 ONBOARDING 业务域的字段 **readonly**,不属于则 **hidden**

#### 场景: create:in_service (创建在职服务工单)
**目标业务域**: `[RENEWAL, BENEFIT]`

**规则**: 同上,字段必须属于 RENEWAL 或 BENEFIT 业务域

#### 场景: create:resignation (创建离职工单)
**目标业务域**: `[RESIGNATION]`

**规则**: 同上,字段必须属于 RESIGNATION 业务域

---

### 3.2 派发场景 (dispatched:*)

所有派发场景使用 `dispatchedPermission()` 函数计算权限。

#### 通用规则:
1. **字段不属于目标业务域** -> **hidden**
2. **字段不在可见字段白名单** (如有) -> **hidden**
3. **admin 角色** -> **visible**
4. **业务类角色** (BUSINESS_ROLE_CODES):
   - 业务组员 (BUSINESS_MEMBER_ROLE_CODES) 且 `businessCanEditVisibleFields=true` -> **visible**
   - 否则 -> **readonly**
5. **非处理人角色** (不在 handlerRoleCodes) -> **hidden**
6. **处理人角色**:
   - 字段在 editableFields -> **visible**
   - 否则 -> **readonly**

## 四、特殊规则

### 4.1 admin 角色特权
**位置**: `field-permission.service.ts:70-75`

```typescript
if (roleCodes.includes('admin')) {
  for (const field of activeFields) {
    permissions.set(field.fieldCode, FieldPermissionMode.VISIBLE);
  }
  return permissions;
}
```

**规则**: admin 角色在任何场景下对所有 `isActive=true` 的字段拥有 **visible** 权限。

---

### 4.2 无角色用户
**位置**: `field-permission.service.ts:77-82`

```typescript
if (roleRows.length === 0) {
  for (const field of activeFields) {
    permissions.set(field.fieldCode, FieldPermissionMode.HIDDEN);
  }
  return permissions;
}
```

**规则**: 无任何角色的用户,所有字段 **hidden**。

---

### 4.3 权限合并规则 (多角色取最高权限)
**位置**: `field-permission.service.ts:176-186`

**优先级**: `visible (3) > readonly (2) > masked (1) > hidden (0)`

当用户拥有多个角色时,对同一字段的权限取最高等级。

---

### 4.4 脱敏规则 (masked)
**位置**: `field-permission.service.ts:195-220`

- **身份证号** (`id_card` / `idCard`):
  - ≤10位: `前2位****后2位`
  - >10位: `前6位********后4位`
- **手机号** (`mobile` / `phone`):
  - <7位: `前2位***`
  - ≥7位: `前3位****后4位`
- **银行卡号** (`bank_account`):
  - ≤4位: `****`
  - >4位: `****...后4位`
- **其他敏感字段**: `前2位***`

## 六、配置基线总结

### 6.1 字段权限配置存储位置
- **表**: `field_permissions`
- **唯一约束**: `(role_id, field_code, scenario)`
- **种子初始化**: `backend/src/database/seeds/seed-field-permissions.ts`

### 6.2 权限计算流程
1. 用户登录 -> 查询 `user_roles` 获取所有角色
2. 根据当前操作场景 (scenario) 查询 `field_permissions`
3. 展开场景别名 (SCENARIO_ALIASES)
4. 多角色权限合并 (取最高权限)
5. admin 角色特判 (全 visible)
6. 应用脱敏规则 (masked 字段)

### 6.3 配置更新方式
- **种子重播**: 重新运行 `seedFieldPermissions()`,使用 upsert 逻辑
- **运行时覆盖**: 不支持,所有权限必须通过数据库配置
